**ictMail 0.33.0 in short**: new features and fixes.

- Send later, Undo Send, and follow-up reminders that come back when nobody replies.
- Warnings before a message goes to a look-alike address or shows many outside addresses to each other, and sender warnings for mail posing as a well-known brand.
- Unsubscribe from a mailing list from the bar above its message, and react to a message with one emoji.
- On a Microsoft account, categories are kept in step with Outlook, and sign-in asks for what ictMail uses on one page.
- An IMAP account can send from several addresses; subscribe to calendars on the web; an Exchange server account searches the organisation's address list.
- Designed mail shows the pictures behind its text, Hebrew and Arabic mail stands at the right, and the files inside `winmail.dat` are listed.
- Polish, Czech, Georgian and Hungarian as preview languages.
- Sturdier: one message that can't be downloaded no longer stops Send/Receive, and a mailbox file that can't be read at start is never replaced by an empty one.
- And more fixes, listed below.

**What's new**

- Choose an action for swiping left or right over a message: delete, archive, mark as read, flag, or none. The row follows the gesture and reveals its action; a short swipe returns it. Both directions start off. On Windows, horizontal mouse-wheel scrolling can also trigger the chosen action.
- Save Message As (File, or a message's right-click menu) saves the message as it was received, byte for byte, so that a Digital signature still checks in the file: for mail of a Microsoft, Exchange server or JMAP account it downloads the server's own copy first, and a signed or encrypted message is saved from the bytes it came as. A message that can't be had that way is saved from what this computer keeps, and the status bar says so; one of which only the headers are here is no longer saved as if it were whole.
- Signing in with Microsoft asks for what ictMail uses on one page, shared mailboxes and their calendars included (not for a personal account, which has none, and Outlook's Favorites are still asked for by themselves), instead of asking again the first time you open a shared mailbox, send from one or tick one of its calendars. An account that signed in before is asked once, in one question, for whatever it doesn't have yet.
- React with one emoji: a button beside Forward opens 👍 ❤️ 🎉 😂 😮 😢, and one click sends a short reaction to the sender (the address is shown beside the emoji; not for mail with a sender warning), as a normal mail filed in Sent Items (for IMAP, JMAP and local accounts; a local account delivers it only to a local account the address names).
- **Czech.** ictMail's window now comes in Czech as a preview language: every text is translated, not yet reviewed line by line by a native speaker, and File › Options names it Čeština (náhled). Dates read day first (11. října 2026, 03.10.2025) with a 24-hour clock and weeks from Monday, and counts take Czech's three plural forms.
- Move to Folder and Copy to Folder, in the dialog Ctrl+Shift+V and Ctrl+Shift+Y open and in the menus, offer the folders of every mailbox you have added, the one in view first and the others under their names, so a message goes into another account's folder without dragging it there.
- **Sender images in People.** With sender images on (File › Options), a contact's picture now shows in place of their initials in the People list and on the contact card, found the same way as a sender's.
- **Polish.** ictMail's window now comes in Polish as a preview language: every text is translated, not yet reviewed line by line by a native speaker, and File › Options names it Polski (wersja zapoznawcza). Dates read day first with a 24-hour clock and weeks from Monday, and counts take Polish's three plural forms.
- **Agents can see whether a message passed its checks.** Reading a message over MCP (or `mail.get`) now says what your mail server found for SPF, DKIM and DMARC, taken only from the server's own result and left out when it gave none; the signing domain is shown only when it is up to 100 bytes long. The command search for agents also looks in the parameter text, so searching for `header` finds View Source.
- Selecting an attachment opens a ribbon for opening, saving or removing the file. Available previews ask for confirmation below the message header, while other attachments leave the message visible. Show Message is available when there is a preview to return from.
- **Follow-up reminders.** Follow Up › Add Reminder… flags a message with a date and time; the reminders window raises it then (Dismiss, Snooze, a double click opens the message), once, also if ictMail was closed at the time. For mail you sent, and in the message you are writing (Follow Up), "Remind me if nobody replies" after 1, 2, 3, 5 or 7 days or on a date: if nobody the message went to has written back in its conversation by then, the reminder is raised and the message flagged; a reply that arrives first cancels it. Clearing the flag, marking the message complete or deleting it ends the reminder. The reminder time is kept on this computer only; the flag syncs with the account as before.
- Send later: Delay Delivery in the Message tab, and Send Later… beside the Send button, hold a message in the Outbox until a date and time you choose. It waits there, where you can change its time or cancel it (it goes back to Drafts), it survives closing ictMail, and if ictMail wasn't running at that time it goes at the next run and the status bar says it is late. A Microsoft account's delayed message is kept and sent by ictMail, not held by the server. The status bar shows when the next one goes.
- Undo Send: File › Options › Wait before sending (off; 5 to 30 seconds) keeps each message in the Outbox for that long after Send, with "Sending in N s · Undo" across the window; Undo, or Ctrl+Z while it shows, puts the message back in a window to write again.
- Calendars on the web can be subscribed to: Calendar › Open Calendar › From Internet… takes an https:// or webcal:// address and keeps a read-only copy up to date every hour (you can choose 15 minutes to a day in File › Info), under Other Calendars. Nothing is read until you subscribe; a private address is kept like a password.
- With Close to system tray enabled, ictMail's icon now shows a little red circle at the top left while an Inbox of your own server accounts has unread mail. Reading or removing the last unread Inbox message clears it, even when desktop alerts are turned off; shared mailboxes, local and imported mail, Archive and custom folders do not count.
- **Hungarian.** Hungarian is available as a preview interface language, with year-first dates and a 24-hour clock (thanks to contributor ferivoq, who also reviewed its wording).
- Pasting a spreadsheet range into an HTML message keeps its rows, columns, empty cells and supported cell formatting after saving and reopening the draft.
- **Recent files for attachments on Windows.** The composer's Attach menu offers up to ten available local files from Windows Recent Items, plus Browse. Files marked by OneDrive Files On-Demand and other paths with Windows reparse points are omitted. The list is read only when opened and stays on the computer.
- Check Names (Ctrl+K) in a message from an Exchange server account also looks names up in your organisation's address list: one match is put in, and when several people match you choose one.
- People has an Address Book for an Exchange server account: choose "Address list" at the top of the list (or Home › Address Book) and type a name in the search box to search your organisation's address list; Email writes to whoever you pick, and Add to Contacts keeps a copy.
- **Files inside `winmail.dat`.** Mail sent from Outlook in its own rich-text format carries its files wrapped in one `winmail.dat` attachment; ictMail now lists the files inside it (with their names and types) beside it, and uses its text as the message's when the message has none of its own. Nothing in it runs or is fetched, and an attached message or object inside it stays in the `winmail.dat`. Mail already in a mailbox is unchanged until it is downloaded again.
- Unsubscribe from a mailing list from the bar above one of its messages, or its right-click menu: in one click where the list allows it (RFC 8058), by a message from your account, or on the list's own page in your browser. ictMail asks first and says what is sent and to whom, and offers it only for mail your mail server confirms came from the list, outside Junk E-mail and with no warning about its sender.
- Sender warnings now also say when a message uses the name of one of the brands phishing impersonates most (Microsoft, Apple, Google, Amazon, LinkedIn, Dropbox, Facebook, WhatsApp, Tesla, YouTube, Adobe, PayPal, ChatGPT) from an address that isn't the brand's, when the sender's domain is made to look like a brand's, when the sender's name is another organisation's domain, and when the sender's domain looks machine-made or can't exist.
- **Georgian.** ictMail's window now comes in Georgian as a preview language: every text is translated, not yet reviewed line by line by a native speaker, and File › Options names it ქართული (საცდელი). Dates read day first with a 24-hour clock and weeks from Monday.
- An IMAP account can send from several addresses (aliases and role addresses its server allows over the same sign-in), each with its own name and signature, picked in the From list, and replies go out from the address a message was sent to.
- A picture that comes as an attachment is shown as a small picture in the message rather than as a chip with its name; a checkbox in File › Options goes back to chips, for every message, and mail in Junk E-mail always shows names.
- An outgoing mail server can be marked "My outgoing server needs no sign-in" in Account Settings, for a relay that takes mail without one; it is then never sent your password, and if it wants a sign-in after all, the error says to untick that choice.
- Mail in Hebrew or Arabic stands at the right of the reading pane, as its sender's `dir` or `direction` says (the first letter in plain text), with a list's markers beside their items; a number or a Latin word inside such a line is still drawn mirrored for now.
- A message dragged onto Calendar, Tasks or People in the module bar opens a new appointment, task or contact filled in from it: its subject, its text, its sender.
- **Warnings before sending.** ictMail asks before a message goes to an address that looks like someone you write to but isn't (a domain, or the part before the @, one character away from a contact's or from someone you've sent mail to), and before 5 or more people outside your organisation, at 2 or more domains, would see each other's addresses in To and Cc (with personal accounts only, there's no organisation, and this isn't asked). You can send anyway, cancel, or, for the outsiders, move them to Bcc in one click. A Reply All to people who were already on the message together isn't asked about. When an agent sends, you're asked in the window and the agent can't answer for you; a script without the window is refused unless it says to send anyway.
- **Pictures behind the text of designed mail.** A newsletter or a piece of stationery that puts a picture behind a table, a cell or the whole message (a banner photograph with a headline on it, a paper texture, a gradient) now shows it, at the size and place it asks for, once or repeated. A picture that is attached to the message or written into it is shown straight away; one on the web is never downloaded for a background, whatever you allow (only the message's pictures proper are), so it cannot tell its sender the message was read. Where the picture is shown as it is over a colour the sender gave the box, the text colours the sender wrote there are kept (they are meant for the picture, which is not looked at, not for the colour under it, so white text over a dark banner stays white); where the sender gave no colour, the picture is softened so its text stays readable, and in the dark theme the picture is dimmed and its text is made readable against the colour turned dark, as before. Dark or default-coloured text over a dark picture is not changed: the sender's text colour is trusted, and the program does not look at the picture's colours. With high contrast on, the picture is left out. Nothing hidden in the message, and no picture behind a box of a pixel or two, is shown.
- **Categories kept in step with Outlook.** On a Microsoft account (not one still on IMAP), a category you make, delete, rename or give another colour in ictMail now changes in Outlook too, a few seconds later (one you delete, once your mail, events and to-dos there no longer carry it), and what you change in Outlook shows in ictMail within a quarter of an hour; before, a category you deleted or renamed here came back. A rename gives your mail, events and to-dos the new name in Outlook too, and the old name leaves Outlook's list once they have it; mail older than what ictMail keeps offline, events outside the days the calendar keeps here or in a calendar you may only read, and contacts keep the old name there, and when only the letter case changes, your mail there keeps the old spelling. A Microsoft account's categories take Outlook's 25 colours. Keeping your tasks, rules, automatic replies and categories in step with Outlook (on a Microsoft account still on IMAP, its tasks and automatic replies) needs your permission to change your To Do lists and your mailbox settings: a new account is asked on Microsoft's sign-in page, and an account you added before is asked in one question (Keep in Step with Outlook) with one Microsoft page for all of it, in place of the separate questions there were; one that already allowed changing its rules or automatic replies isn't asked again for its categories. If you close the question, it isn't put again by itself until ictMail starts again or you open another mailbox (a change of your automatic replies, or Allow in the Categories window, puts it again); File › Info has one line for it per account, with Ask again. Until you allow it, and until ictMail has checked (it can't while offline), that account's categories can't be changed in ictMail, nor a new one put on its items, and the Categories window says so, with Allow. A category that was only on this computer stays off Outlook's list and says so, with Add to Outlook; mail, events and to-dos you give it still carry its name to Outlook, as before.
- In an organisation, an administrator may need to approve ictMail again before it can change your To Do lists and mailbox settings. When you allow keeping in step with Outlook (in its question, or with Ask again on the account's Sync with Outlook line in File › Info) and Microsoft answers that an administrator has to approve it, ictMail opens Approval Needed: there an administrator approves ictMail for everybody (I'm an administrator: approve it for my organisation), or you copy a message with the link for your administrator (Copy a message for my administrator).

**Fixes**

- HTML mail looks more as it does in Outlook: links are underlined only where the message doesn't say otherwise, so a shop's or a service's mail no longer has a line under every button, heading and price; buttons are drawn as buttons, as wide as their card where they ask to be, with their words in the middle, instead of as highlighted words; labels and badges are rounded boxes; mail from templates that nest their layout deeply (a shop's delivery notice) keeps its buttons and boxes; a button whose border is its own colour has no darker edge; and a message whose plain-text copy lost a character no longer says that characters couldn't be read when that copy isn't what is shown.
- Renaming or deleting a category no longer changes it on events in other people's calendars, nor, on a Microsoft account whose categories are kept in step with Outlook, on the mail and other items of its shared mailboxes: those keep the name they had.
- On a Microsoft account added by an alias or a sign-in name, the events in your other calendars now give reminders, and those calendars are listed with your own and can be sent with Email Calendar; before, they were taken for somebody else's and listed under Shared Calendars.
- Renaming or deleting a category now changes it on the events of a calendar kept on a server, there too, and Undo puts it back there; before, those events kept the old name on the server.
- Holding Space on a category's Delete in the Categories window now deletes only that category; before, the categories after it could be deleted too.
- On a Microsoft account, keeping to-dos, rules and the calendar in step with Outlook now waits before trying again after a try that failed slowly; before, a try that failed after 30 seconds or more was made again at once.
- An agent's undo or redo that changes an account and also sends something to a server (mail to people, a category to Outlook) now needs your yes to send as well; before, the yes for accounts was enough.
- An agent allowed to send but not to change settings now needs your yes to change rules, also when the change sends something to a server or an undo puts rules back; before, its permission to send was enough.
- A signature renamed in File › Signatures keeps its new name when you press Rename again, click elsewhere, press Tab, choose another signature, click Save or go Back, not only when you press Enter; Escape still keeps the old name.
- A notch of a mouse wheel now scrolls about three lines, as in other desktop programs, instead of barely two; touchpad scrolling is unchanged.
- Adding an attachment (or a picture) in a pop-out message window no longer brings the main window forward: the window that asked comes back in front once the file is chosen.
- In File › Signatures, the Colour menu stays open when you click in its colour box, so a colour of your own (`#rrggbb`) can be typed and applied.
- The "Your name" hint in account setup now says plainly what it is for: the name people you write to will see.
- Move to Folder's search finds a folder from the start of each word, so "Sum 2025" finds "Summer 2025".
- Copying a calendar item that has files attached is now refused, with the reason, rather than making a copy without its files.
- A subscribed calendar with an event that has no UID, or an empty one, no longer changes on every refresh.
- Save Mailbox As writes large mailboxes a message at a time, avoiding a second in-memory copy of all their content and the complete export file. Header lines remain readable by older versions, and messages beyond the reader's size limit are refused. A failed export leaves an existing destination unchanged.
- One message that can't be downloaded no longer stops the rest of Send/Receive. After a connection error on a message, ictMail opens a fresh connection and carries on with the next message and the folders after it; a message that fails in three runs in a row is left out and said so, in File › Info too, where Try again takes it up again, and a connection that fails again on the next message ends the run as before. A record that fails its check in the middle of an encrypted connection now says in plain words that antivirus or firewall software that scans mail connections is the usual cause.
- Mail is fetched when ictMail starts again for accounts whose password or sign-in is kept in the system's credential store: the first automatic Send/Receive no longer starts before the store has answered (and then leaves the account out until the next interval).
- Signing in with Microsoft or Google no longer hangs when the computer picks a local port that browsers refuse to open (such as 6000 or 6665-6669); another port is used.
- An attachment with a non-ASCII or very long name keeps its extension (`.pdf`, `.docx`) in mail programs that read only the plain `name=` or `filename=`.
- Clicking in the text field of a menu no longer closes the menu: a colour typed by hand in Font Color or Text Highlight Color, and the folder search of Move, Copy to Folder and Move Folder.
- Add Account now recognises IONOS mail on your own domain and fills in the IMAP and SMTP servers for your country.
- A calendar or Microsoft To Do update that came back signed in as somebody else than the account is now refused whole, on the desktop and on Android: nothing is sent with that sign-in (no new meeting or to-do goes up to somebody else's account), nothing of it reaches your calendar or your to-dos, its sign-in isn't kept, and you are told to sign in again as the account. Mail kept in step through Microsoft Graph is checked the same way: with somebody else's sign-in no message leaves your Outbox and nothing of your mail is read or changed. Before, the desktop and the phone's To Do took in what it brought and refused only the sign-in.
- An appointment made in ictMail on a Microsoft account now shows in Outlook in your own time zone, not in UTC.
- A meeting invitation, an answer to one or a cancellation in an Exchange server account comes in with its date, its sender and its size, and is listed where it arrived, instead of with no date at the very end of the folder.
- The Link button in the signature editor (File › Signatures) opens the same Insert Link dialog as writing a message does, so a signature can link to a web address, an email address or a phone number; Ctrl+K works there too.
- On Windows, Shift+Delete now deletes the selected message permanently (with the confirmation it always asked), as the ribbon's Delete Permanently does: the press was going to the system's cut function before ictMail ever saw it. Holding Shift while clicking the ribbon's Delete now deletes permanently too, as in Outlook.
- The Move to Folder and Copy to Folder menus no longer stutter as the pointer moves over them when the mailbox holds thousands of folders in several accounts: the folders are read once, when the menu opens.
- Remove Imported Duplicates now goes ahead when you say yes to its question; it refused with "`confirmed` isn't a parameter of this command". Attach Item had the same fault. The command is also on the ribbon, under Folder › Clean Up.
- Changing how the message list is sorted or arranged (Arrange By, Reverse Sort, conversations, groups, single line, preview lines, ready-made views, tighter spacing) now scrolls the list to the selected message and centres it instead of leaving it out of view.
- Arranged by Size, messages of the same size are in date order, newest first, as those of one sender or one subject already were.
- Texts that stayed in English whatever the interface language are translated now: the folder menu (New Folder…, Rename Folder…), Unpin in the message menu, the reading pane buttons, the text and highlight colours, the note on the Send / Receive tab, what the appointment and recurrence windows say is missing, the Safe and Blocked Senders lists, the column names of About › Contributors, and the help when a Microsoft sign-in comes to nothing.
- Text pasted in Consolas, Menlo or DejaVu Sans Mono comes into the composer as Courier New, and a signature in a font a later version adds keeps its bold, colours and sizes here, losing only the font.
- ictMail sends the IMAP ID command (RFC 2971) after sign-in where the server offers it, so Coremail servers such as 163.com and 126.com accept it.
- `mail.markAllRead` refuses a `folder` that isn't an id or that names no folder, instead of quietly marking the folder in view, and its answer names the folder it marked.
- `folder.new` makes the folder in the account it is given, refuses an account that isn't there, and refuses a parent of another account's.
- A header block written again after its pack was cut short is named where it went, and only the header block itself is excused from the check that a part's bytes are here.
- Opening a message after opening the reminder of a recurring appointment no longer asks about that appointment's series instead of opening the message.
- When ictMail can't tell at start whether your mailbox file is there (access refused, a folder out of reach), it says so and keeps nothing, instead of opening an empty mailbox that a later save would have written over the real one.
- With the reading pane at the bottom, the message list keeps the height you dragged it to the next time ictMail starts.
- With a message being written in the reading pane (a draft after Continue editing, a New Email, a reply), clicking a message in the list now saves what you were writing to Drafts and shows the message you clicked, so that Delete, Reply and the rest act on the message you see, never on one hidden behind the message being written; Next Message, Select All and a new-mail alert do the same, and the list's keys no longer move a selection you can't see. A draft with no changes isn't saved again, a message in a window of its own stays open, and a draft that can't be saved stays in the reading pane with the selection as it was.
- With 400 or more categories in a Microsoft account's list, a colour changed in Outlook and a category made there now show in ictMail; before, they stopped coming in.
- Category names that differ only in the case of a letter outside A-Z, such as «Ärger» and «ärger», are now one category, as «Red» and «red» always were: on a list, on an item given both, on an event from its server, in the Categorize menu, in Advanced Search, and in an Outlook data file's list and on its contacts; before, both could be there.
- A time with a one-digit-hour offset (`+2:00`) is no longer read as twelve hours ahead, and a space before the offset (`09:30 +02:00`) is accepted, for Snooze, Follow-up and automatic replies set from the command line or an agent.

ictMail keeps your mailbox in its settings folder and saves as you go; one window per mailbox. With a Microsoft 365 or Outlook.com account you sign in on Microsoft's page, and the sign-in is kept by the system's credential store (Windows, macOS, and the Secret Service of GNOME Keyring or KWallet on Linux). What works, and how far each part is from Outlook, is in the [README](https://github.com/GITHUB_REPOSITORY#what-works-today) and in `docs/gaps.md`.

The builds are not signed with a publisher certificate yet: Windows SmartScreen and macOS Gatekeeper will ask before running them.
